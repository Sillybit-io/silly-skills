# Security Policy

Please report private vulnerabilities through [GitHub Security Advisories](https://github.com/Sillybit-io/silly-skills/security/advisories) when possible. You may also open a GitHub issue for a security concern that is safe to disclose publicly.

This project follows a no-secrets/no-PII policy. Do not commit credentials, tokens, private information, or other sensitive data to the repository.

gitleaks runs in CI on every pull request.
